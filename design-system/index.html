Design System do LMS

Linguagem visual do produto: base creme, títulos navy em Syne, ação em ciano, e o lado lúdico em pastéis com borda preta e sombra crisp — extraída da referência applause.team. Todo componente deriva de variáveis CSS, então o white-label por cliente é só sobrescrever tokens.

Arquitetura

White-label por cliente

Para trocar o tema de um tenant, sobrescreva só as variáveis do cliente. Exemplo de um cliente com identidade laranja: 

<style>
:root {
  --lms-primary:      #E8641B;
  --lms-primary-deep: #C24F10;
  --lms-heading:      #2B1A0E;
  --lms-accent:       #5A2E00;
}
</style>
